## 📌 Overview
Modern React Single-Page Application (SPA) designed to interface with the Node.js/Express REST API for full Create, Read, Update, and Delete operations.

## ✨ Frontend Features
- **Create Articles**: Dynamic modal form capturing title, category, excerpt, full article content, and tag arrays.
- **Read & Filter**: Real-time filtering by category pills and keyword search bar across titles and summaries.
- **Update**: Pre-populates existing article data into the modal form for instant updates.
- **Delete**: Safely removes records with confirmation prompt and optimistic state synchronization.
- **Upvote System**: Live counter updating article popularity.
- **Article Reader Modal**: Deep-dive full screen reader with reading time metrics and tag badges.

## 🚀 Setup & Execution
1. Navigate to this directory:
   ```bash
   cd "Level-3-Advanced/Task-1-FullStack-CRUD/frontend"
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start Vite development server:
   ```bash
   npm run dev
   ```
   *Runs on `http://localhost:5173`.*
