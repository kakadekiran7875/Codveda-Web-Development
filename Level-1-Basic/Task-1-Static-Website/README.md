## 📌 Task Overview
- **Task Name**: Build a Simple Static Website
- **Level**: Level 1 (Basic)
- **Domain**: Web Development
- **Internship**: Codveda Web Development Internship

## 🎯 Objective
As defined in the official Codveda Web Development Task List:
- Create a basic static website with multiple pages, such as a homepage, about page, and contact page.
- Use HTML for structure and CSS for styling.
- Add essential elements like navigation bar, images, and footer.
- Ensure basic responsiveness using CSS media queries.

## ✨ Features
1. **Multi-Page Architecture**:
   - `index.html`: Corporate homepage with hero banner, terminal code card, service highlights, and key metrics.
   - `about.html`: Company background, core mission statement, values, and engineering pillars.
   - `services.html`: Detailed service catalog covering Web Development, App Development, AI/ML Automation, Data Analysis, Digital Marketing, and SEO Optimization.
   - `contact.html`: Contact channels (support@codveda.com, www.codveda.com, @codveda) and interactive contact form with instant validation.
2. **Responsive Design**:
   - Custom CSS Flexbox and Grid layouts.
   - Media queries catering to desktop (>992px), tablet (768px - 992px), and mobile devices (<768px).
   - Dynamic mobile hamburger menu with smooth toggle transition.
3. **Aesthetic Excellence**:
   - Modern color palette with sleek emerald green (`#00b48a`), slate dark surfaces (`#0f172a`), and modern typography (Plus Jakarta Sans).
   - Glassmorphic navigation header with backdrop blur.

## 🛠️ Technologies Used
- **HTML5**: Semantic document structure (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **CSS3**: Custom properties (CSS variables), Flexbox, CSS Grid, media queries, animations.
- **JavaScript (ES6+)**: DOM manipulation for mobile navigation toggling and contact form state simulation.

## 🚀 How to Run
1. Open this directory in your terminal or file explorer:
   ```bash
   cd "Level-1-Basic/Task-1-Static-Website"
   ```
2. Double-click `index.html` to open it in your default web browser.
3. Alternatively, serve with VS Code Live Server or run:
   ```bash
   npx serve .
   ```
