## 📌 Task Overview
- **Task Name**: Create a Portfolio Webpage
- **Level**: Level 1 (Basic)
- **Domain**: Web Development
- **Internship**: Codveda Web Development Internship

## 🎯 Objective
As defined in the official Codveda Web Development Task List:
- Design a personal portfolio page to showcase projects or skills.
- Use HTML and CSS to create a single-page layout.
- Add sections for an introduction, projects, and contact information.
- Style the page with custom fonts, colors, and animations.

## ✨ Features
1. **Sleek Single-Page Architecture**:
   - **Hero Section**: High-impact introduction with developer badge, bio, avatar card with quick stats, and call-to-action buttons.
   - **About Section**: Professional narrative outlining developer passions, engineering philosophies, and Codveda internship journey.
   - **Skills Matrix**: Categorized tech stack breakdown (Frontend, Backend, Databases, DevOps & Tooling) with interactive hover effects.
   - **Dynamic Projects Showcase**: Interactive project cards equipped with live category filters (All, Full Stack, Frontend & React, JavaScript & CSS).
   - **Milestones & Experience**: Clean chronological career timeline highlighting the Codveda Web Development Internship.
   - **Contact Center**: Direct contact channels (Email, LinkedIn, GitHub) alongside an interactive contact form with instant validation feedback.
2. **Visual & Aesthetic Design**:
   - Futuristic dark mode palette (`#0a0e17`, `#111827`) with cyan and purple gradient accents.
   - Glassmorphic card styling, subtle backdrop blur, and smooth CSS transitions.
   - Pulse animations, glowing hover states, and modern typography using Google Fonts (Outfit & JetBrains Mono).
3. **Responsiveness**:
   - Fully fluid layout adapting seamlessly to desktop monitors, tablets, and smartphones.

## 🛠️ Technologies Used
- **HTML5**: Semantic single-page layout structure.
- **CSS3**: Custom properties, Glassmorphism, CSS Grid, Flexbox, Keyframe animations.
- **JavaScript (ES6+)**: Scroll spy navigation highlighting, dynamic project filtering by data attributes, and form submission feedback.
