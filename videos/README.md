# Project Demonstration Videos

This directory contains video walkthroughs and demo clips created for the **Codveda Web Development Internship** submission and LinkedIn showcase.

## Required Video Demonstration Details

According to the official Codveda Internship guidelines:
1. **Host on LinkedIn**: Create a professional video showcasing your internship projects and achievements.
2. **Tag Codveda**: Tag **Codveda Technology** (@codveda) in your post.
3. **Use Hashtags**:
   - `#CodvedaJourney`
   - `#CodvedaExperience`
   - `#FutureWithCodveda`
   - `#CodvedaAchievements`
   - `#CodvedaProjects`
4. **Include GitHub Link**: Link to this repository in your LinkedIn post.

## Video Organization
- `level-1-walkthrough.mp4` / `.webm` (Demonstration of Level 1 Tasks 1, 2, 3)
- `level-2-walkthrough.mp4` / `.webm` (Demonstration of Level 2 Tasks 1, 2, 3)
- `level-3-walkthrough.mp4` / `.webm` (Demonstration of Full-Stack CRUD & Authentication systems)
- `codveda-internship-complete-showcase.mp4` (Full overview video for submission form and LinkedIn)
