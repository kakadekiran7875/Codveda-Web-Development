# Project Screenshots

This directory contains visual captures demonstrating the user interface, responsiveness, and key features of each completed task in the **Codveda Web Development Internship**.

## Directory Mapping

Place your screenshots organized by task:

- `level-1-task-1/` - Static Multi-page Website (Home, About, Services, Contact, Mobile views)
- `level-1-task-2/` - Personal Portfolio (Hero, Skills, Projects, Experience, Mobile view)
- `level-1-task-3/` - JavaScript Interactivity (Dropdown, Modal, Form Validation in action)
- `level-2-task-1/` - Responsive Web Design with Flexbox & Grid (Desktop, Tablet, Mobile)
- `level-2-task-2/` - To-Do List App (Tasks list, Adding tasks, Filters, LocalStorage persistence)
- `level-2-task-3/` - React Weather App (Search, Weather metrics, Forecast, Responsive layout)
- `level-3-task-1/` - Full-Stack CRUD Application (Dashboard, Create, Update, Delete, API logs)
- `level-3-task-2/` - User Authentication System (Registration, Login, Protected Dashboard, Logout)

## Recommended Screenshot Formats
- Format: `.png` or `.webp`
- Resolution: Clear desktop (1920x1080 or 1440x900) and mobile (375x812)
- High contrast and legible UI states
